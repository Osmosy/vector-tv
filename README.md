# Vector TV

Навык для агента: убрать рекламу, телеметрию и предзагруженный мусор с **Android TV / Google TV**
и поставить свой главный экран — через ADB, **без root и без прошивки**.

Телевизор не перепрошивается: меняются только состояния пакетов (`pm disable-user`), система
остаётся на месте, откат — обратные команды по записанному состоянию.

## Зачем

Производители Android TV зарабатывают на рекламных строках и телеметрии. Штатный путь — «искать
кастомную прошивку и шить по инструкции из форума». Он опасен и необратим. Здесь другой путь:
у Android TV тот же debug bridge, что у телефона. Включили отладку, подключились по Wi-Fi —
и агент отключает лишнее теми же вызовами, что делают настройки Android.

| Прошивка | Этот навык |
|---|---|
| перезаписывается раздел с системой | система не меняется |
| нужен bootloader, риск кирпича при обрыве | риск только при ошибке в списке пакетов |
| откат — перепрошивка или recovery | `pm enable --user 0` по списку |
| теряется гарантия и OTA | гарантия и OTA остаются |
| нужен образ под модель | нужен ADB и список пакетов под модель |

## Что в репозитории

```
skills/vector-tv/
  SKILL.md                          порядок работы: подготовка → бэкап → список → отключение → лончер → проверка → откат
  references/safety-and-restore.md  стоп-список пакетов с причинами и номерами issue, порядок отката
  references/ecosystem.md           кто что делает среди открытых проектов, «чем это не прошивка», не-Android ТВ
  scripts/tv-inventory.sh           снять инвентарь по ADB и восстановить по нему
```

## Установка навыка

```bash
git clone https://github.com/Osmosy/vector-tv
cp -r vector-tv/skills/vector-tv ~/.hermes/skills/devops/
```

Дальше агент находит его сам по описанию; вручную — `skill_view(name='vector-tv')`.

Нужен `adb` (пакет `android-tools-adb` в Debian/Ubuntu, `android-platform-tools` в macOS).

## Быстрый старт

```bash
# 1. на телевизоре: О телевизоре → Сборка ×7 → Для разработчиков → Отладка по USB
# 2. на компьютере:
adb pair 192.168.1.50:41234        # Android 11+: порт и код — с экрана ТВ
adb connect 192.168.1.50:5555      # на ТВ подтвердить «Разрешить отладку»

# 3. бэкап — обязательно
skills/vector-tv/scripts/tv-inventory.sh inventory 192.168.1.50

# 4. отключить один пакет и посмотреть на телевизор
adb -s 192.168.1.50:5555 shell pm disable-user --user 0 com.google.android.tvlauncher.recommendations

# 5. откат
skills/vector-tv/scripts/tv-inventory.sh restore 192.168.1.50 tv-inventory-2026-11-01T18-00
```

## Главное правило

Есть пакеты, после которых телевизор не загружается. Это не теория: в проекте, из которого собрано
знание, каждый пункт стоп-списка — чей-то мёртвый телевизор (Mi TV Stick, Haier H50H5F,
TCL 43S5400A). Стоп-список и бэкап не обсуждаются, порядок «сначала новый лончер, потом отключить
старый» тоже.

## Источники знания

Навык собран из открытых проектов и их issue-трекеров:

- [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) — деблоат по ADB и списки пакетов по моделям, номера issue в стоп-списке оттуда;
- [simbasjungles/free-my-tv](https://github.com/simbasjungles/free-my-tv) — APK-лончер, MIT;
- [smartago/tvboxtools](https://github.com/smartago/tvboxtools) — менеджер HOME и MCP-сервер для агента, Apache-2.0.

Код и тексты этих проектов в репозиторий не переносились: у cleanyourtv нет явной лицензии,
поэтому оттуда взято только знание (имена пакетов и причины по номерам issue), изложенное заново.
Подробнее — [NOTICE.md](NOTICE.md).

## Что проверено

На машине автора: `adb 1.0.41 (34.0.5)` работает; `scripts/tv-inventory.sh` проходит `bash -n`,
без устройства отдаёт код 1 с внятной причиной, без аргументов — код 2, `restore` на
несуществующем каталоге — код 2.

Не проверено: ни одна команда не выполнена на живом телевизоре. Первый прогон — с владельцем
рядом и с бэкапом.
