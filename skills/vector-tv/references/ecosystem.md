Логичное разделение работы: **деблоат — cleanyourtv** (у него единственные проверенные списки
по моделям и защита от кирпича), **лончер — free-my-tv** (готовый APK, MIT, работает и на
webOS/Tizen, где ADB нет), **управление HOME и MCP — tvboxtools**.

## На телевизоре владельца

Уже стоит **free-my-tv**, ставился через ADB по Wi-Fi (IP телевизора, отладка в меню
разработчика, root не нужен). То есть штатный лончер уже заменён; повторный деблоат начинать
с бэкапа текущего состояния, а не с чистого листа.

## Чем это не прошивка

| Прошивка (firmware) | Наш путь |
|---|---|
| раздел с системой перезаписывается | система не меняется, меняются состояния пакетов |
| нужен bootloader, риск кирпича при обрыве | риск при ошибке в списке пакетов, не при передаче файла |
| откат — только перепрошивкой или recovery | `pm enable --user 0` по записанному списку |
| теряется гарантия и OTA-обновления | гарантия и OTA остаются, обновление может вернуть отключённое |
| нужен образ под конкретную модель | нужен только ADB и список пакетов для этой модели |

## Не-Android телевизоры

ADB там нет, `pm`-команд нет. Что можно без перепрошивки:

- **Samsung (Tizen), LG (webOS)** — free-my-tv ставит свой лончер и там (APK/веб-пакет отдельно);
  телеметрию и рекламные полки отключают в настройках и через блокировку DNS на роутере.
- **Roku, Vizio, Hisense VIDAA** — только настройки приватности пультом + DNS-блокировка
  рекламных доменов на роутере.
- **Apple TV** — не трогается: ни ADB, ни сторонних лончеров.

Общий приём для всех: на роутере отдать телевизору отдельный профиль DNS с блокировкой
рекламных и телеметрических доменов вендора. Это не заменяет деблоат, но снимает наружку,
которую изнутри не выключить.
